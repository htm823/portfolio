Contact Form & Dashboard

PHPとMySQLを用いて開発したお問い合わせ管理システムです。

ユーザーはフォームからお問い合わせを送信できます。
管理者は管理画面からお問い合わせの閲覧・検索・管理を行えます。

HTML、jQuery、PHP、MySQL、Bootstrapを用いて開発しました。

  • View GitHub Repository

Preview

Background

PHPによるフォーム送信、バリデーション、データベース連携の基礎を学ぶために制作しました。
入力値の検証、データベースへの保存・取得、表示前のデータ整形など、一連のバックエンド処理の実装を目的としました。

Features

お問い合わせの送信
必要事項を入力することで、お問い合わせを送信できます。
住所の自動入力
郵便番号を入力すると、住所を自動入力できます。
お問い合わせ一覧の閲覧
管理者はログイン後、お問い合わせ内容を一覧で確認できます。
お問い合わせ検索
キーワードを指定してお問い合わせを検索できます。
お問い合わせの並び替え
新しい順・古い順に並び替えられます。
既読・未読ステータス
未読のお問い合わせを視覚的に把握しやすくなっています。

Technology Choices

PHPのフォーム処理とデータベース連携の理解を目的としていたため、フレームワークは使用せず、PHPのみで実装しました。
スタイリングには開発効率を考慮してBootstrapを採用しました。

また、日本の住所入力に特化しており、導入が容易なことから、住所自動入力ライブラリとしてyubinbango.jsを採用しました。

System Design

BootstrapのSecondaryカラーをベースに、シンプルで分かりやすいUIを目指しました。
エラーメッセージや未読ステータスには赤色を使用し、ユーザーが重要な情報を見落としにくいデザインにしました。

管理画面には左固定のサイドメニューとページネーションを配置しました。
1ページあたりには、一目で把握できる情報量として、5件分のお問い合わせが表示されるようにしました。

Implementation Highlights

データベース接続処理を共通化し、複数のファイルから再利用できる構成にしました。
接続情報は環境変数として管理し、異なる環境でも、設定のみの変更で簡単に動作するよう設計しました。

お問い合わせ入力から送信完了までのデータ保持、および管理画面のログイン状態の管理にはセッションを利用しています。

データを画面へ出力する際にはエスケープ処理を追加し、安全にHTMLが生成されるよう実装しました。

ローカル開発環境では、実際のメールアドレスへ送信することなくメール送信を確認できるよう、Mailtrapを使用しました。
管理画面の動作を確認するためのデモアカウントを用意しています。

セットアップ方法やデモアカウントの詳細については、READMEをご覧ください。

Challenges & Solutions

バリデーションエラー発生時やブラウザの戻る操作を行った際に、入力内容が失われてしまうことが課題でした。
解決策として、入力内容をセッションに保持し、送信完了まで同じデータを利用する仕組みを実装しました。

管理画面の認証にもセッションを利用し、ログインからログアウトまでの認証状態を維持できるようにしました。
セッション管理やフォーム処理の流れについて理解を深めることができました。

Security

セキュリティを考慮した実装を心がけました。

パスワードは、password_hash()を用いてハッシュ化し、ハッシュ化された状態でデータベースに保存しました。
認証にはpassword_verify()を使用し、入力パスワードとハッシュ化されたパスワードが一致しているか確認可能にしました。

また、SQLインジェクション対策として、データをデータベースに保存する際にpreparedステートメントを使用しました。
XSS対策としては、入力データやデータベースから取得した値を画面へ出力する際にエスケープ処理を追加しました。

管理画面はセッション認証によって保護し、認証済みのユーザーのみが管理機能へアクセスできるようにしています。

Future Improvements

今後は、ユーザー登録機能の追加や、PHPUnitを用いた自動テストの導入に取り組みたいと考えています。

また、データベース設計の正規化や、管理画面のレスポンシブ対応を進めることで、保守性と利便性を向上させたいです。
実際の利用シーンやターゲットユーザーを明確にし、仕様を見直したうえで、本番環境へのデプロイを行う予定です。
