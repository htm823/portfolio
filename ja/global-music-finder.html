Global Music Finder

海外の音楽を検索しやすくする音楽検索アプリ。
言語別の楽曲検索、楽曲・アーティスト名のコピー、楽曲の試聴が可能。

HTML、SCSS、JavaScript、iTunes APIを用いて開発。

  • View GitHub Repository

Preview

Background

韓国語や中国語の音楽を聴きたいと思ったとき、語学力がなくて、検索の文字入力に困った経験がありました。
知らない言語の音楽を簡単に検索できるアプリがあればいいなと思い、このアプリを制作しました。

Features

言語別の楽曲検索
言語ごとに分かれたページから、目的の音楽を探せます。
楽曲・アーティスト名のコピー
  • ワンクリックでコピーでき、文字入力せずに検索できます。
  • 外部ブラウザで検索するときにも活用できます。
楽曲の試聴
音源をすぐに再生できるため、効率よく新しい音楽を探せます。

Technology Choices

JavaScriptによるAPI連携の実装に重点を置きたかったため、HTML・SCSS・JavaScriptを採用しました。

APIには、無料かつ認証不要で利用できるiTunes Search APIを選択しました。
多言語の楽曲を幅広く検索できるという点においても、今回のアプリに向いていると考えました。

System Design

Final Design
検索結果をスクロールしても言語選択タブが見えるようにするため、操作パネルを左端に固定しました。
言語ごとにUIのアクセントカラーを統一することで、今開いているタブをユーザーが視覚的に把握できるようにしました。
Initial Design
当初、言語タブを画面上部に配置していましたが、スクロールすると操作パネルが画面外に出てしまう問題が発生しました。
そのため、デザインの見直しを行い、操作パネルを左端に固定配置しようと考えました。

Implementation Highlights

JavaScriptは機能単位でファイルや関数を分割し、保守性と拡張性を意識した構成にしました。
ページごとに必要なコードのみ読み込む構成にすることで、不要な処理を避けられるよう工夫しました。

検索結果の生成にはテンプレートリテラルを採用しました。
HTML構造をまとめて記述できるため、createElement()を使うよりも可読性と保守性が上がると考えました。

CSS設計においては、BEM形式を採用しました。
セクションや各パーツなど、ブロックごとにスタイルを管理しやすく、SCSSの記法と相性が良いためです。

言語ごとの可変スタイルは、別ファイルにカラーパレットをあらかじめ作成しました。
SCSS変数とラジオボタンで制御することで、追加するコードを必要最低限に留めるよう意識しました。

Challenges & Solutions

試聴ボタンの実装と状態管理に苦労しました。
当初は各検索結果にaudioタグを配置しましたが、検索結果が多い場合にaudio要素が増えすぎる問題が発生しました。

その後、別の実装方法も試しましたが、音源を正常に再生できませんでした。
最終的に、音源の再生を優先してaudioタグによる実装を採用しています。

再生状態に応じたアイコンの切り替えは未実装のため、今後改善したい課題として残しています。

Future Improvements

今後は、再生状態に応じて試聴ボタンのアイコンを切り替えられるよう改善したいと考えています。
現在は音源が再生されてもアイコンが変化しないため、再生中か停止中かを視覚的に判断しづらい状態です。

検索結果をスクロールしても検索ボックスを利用できるよう、画面上部に固定表示する予定です。
検索のたびにページ上部へ戻る必要がなくなり、操作性の向上につながると考えています。
